1 · Introducción

¿Qué es transcribir?

Transcribir es pasar todo lo que se dice en una entrevista o focus group grabado a texto escrito. Esto permite leer, analizar y entender mejor lo que dijeron las personas, y es la base sobre la que se construye todo el análisis cualitativo.

La actividad evaluativa de análisis de datos requiere que llegues con tus transcripciones debidamente elaboradas en formato limpio. No será posible avanzar con el análisis sin ellas: cuanto mejor estén hechas, más fácil será descubrir patrones y sacar conclusiones.

Base del análisis

Sin transcripción no hay codificación posible: es el insumo que se sube a Atlas.ti.

Formato limpio

Usaremos la transcripción literal limpia: se omiten muletillas y pausas, se conserva el contenido.

4 · Herramientas

Herramientas recomendadas

TurboScribe

Transcribe automáticamente el audio. Se sugiere usar el modo "delfín" o "ballena" para mayor precisión.

Tactiq

Alternativa para transcribir y luego revisar el texto según las indicaciones de este recurso.

Ambas herramientas entregan un primer borrador: siempre debes revisarlo y limpiarlo según el formato indicado.
